Variance Table

A table of up to three metrics by segment for any month against the previous month or last year, with colour-coded changes and totals.

When to use it

Use it when people want the numbers: each segment this month against last month or last year, with the changes coloured.

Questions it answers

  • Which segments moved most against last month?
  • Is the total up or down on last year?
  • Which metric is driving the change?

How to use it

  1. On your dashboard page, add a grid with the columns below (or map your own header names – see below). Keep it on the same page – tuck it behind the chart rather than hiding it, and make it tall.
  2. Add an HTML container (one that runs JavaScript) and paste the snippet.
  3. View the page. The chart finds the grid, reads every row and draws itself; it updates when filters change the grid.

Your own column names

The chart looks for the default headers above. If your grid's headers are different, map them by key with data-columns on the placeholder – the chart then shows your names too. data-labels (same keys) changes just the on-screen names, and data-title changes the heading. For grids that draw rows in batches, data-grid-class and data-scroll-class name the grid's container and its scroll box so every row is read.

Example
<div data-chart-embed="variance-table" data-columns='{"month":"Your Month Header","v3":"Your Metric Header"}' data-title="Your title" style="height:100%"></div>

What it does

  • Current, comparison and change columns for each metric, with a total row
  • Compare to the previous month or the same month last year; pick any month
  • Changes shaded green or red by size; click a column to sort by it
  • A card per metric with its total and change

Data & security

  • Reads only what is drawn on the page for the viewer, so the viewer's normal permissions still apply
  • Calculations happen in the viewer's browser; nothing is uploaded or sent anywhere
  • The only downloads are this script and Chart.js, both integrity-checked
  • No logins, API keys, cookies or browser storage
