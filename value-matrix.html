What is a Value per Unit Heatmap Matrix?

A value matrix is a heatmap of value per unit across two dimensions, weighted by volume, to find high- and low-value combinations. This Value Matrix is free to copy and paste: it reads a grid on the same page – in a MicroStrategy (Strategy One) dashboard's HTML container, or any web page – and draws itself in the browser, with no plugin, server or data upload.

When to use it

Use it when a grid compares cohorts on a value per unit – value per customer, per order or per player – across two groupings, with no date involved.

Questions it answers

  • Which combination of the two groupings is worth the most per unit?
  • Is a group strong everywhere, or only in one column?
  • Are the best-looking cohorts big enough to matter?

How to use it

  1. On your dashboard page, add a grid with the columns below (or map your own header names – see below). Keep it on the same page – tuck it behind the chart rather than hiding it, and make it tall.
  2. Add an HTML container (one that runs JavaScript) and paste the snippet.
  3. View the page. The chart finds the grid, reads every row and draws itself; it updates when filters change the grid.

Your own column names

The chart looks for the default headers above. If your grid's headers are different, map them by key with data-columns on the placeholder – the chart then shows your names too. data-labels (same keys) changes just the on-screen names, and data-title changes the heading. For grids that draw rows in batches, data-grid-class and data-scroll-class name the grid's container and its scroll box so every row is read.

What it does

  • One cell per pair of Dimension A and Dimension B, shaded from low to high value
  • Row, column and overall totals are averages weighted by units, not simple averages of the cells
  • Switch between up to three value columns (e.g. 12, 18 and 24-month value)
  • Sort rows and columns by volume or by value
  • Small cohorts are outlined and left out of highest/lowest – set the cut-off with data-min-volume (default 1% of all units)
  • Several grid rows for the same pair (e.g. split by a third column) are combined, weighted by units
  • No Chart.js needed – drawn as a plain table

Data & security

  • Reads only what is drawn on the page for the viewer, so the viewer's normal permissions still apply
  • Calculations happen in the viewer's browser; nothing is uploaded or sent anywhere
  • The only download is this script, integrity-checked
  • No logins, API keys, cookies or browser storage
