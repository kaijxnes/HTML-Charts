Custom charts in MicroStrategy, without a plugin

You can add charts MicroStrategy doesn't have – ribbon charts, Sankey diagrams, cohort heatmaps, PVM bridges – to any dossier or dashboard with an HTML container and a grid. No visualization plugin, admin install or server: the chart reads the grid on the page and draws itself in the viewer's browser.

How to add one

  1. Build the grid. Put a grid on the same page with the attributes and metrics the chart needs – e.g. Month, Region and Orders. Keep it on the page (tucked behind the chart) rather than hidden, and make it tall.
  2. Turn off incremental fetch. In the grid's properties, switch off incremental fetch (or raise the block size) so all rows are loaded. Otherwise the grid only holds the first block of rows.
  3. Add an HTML container. Insert an HTML container (in Strategy One / MicroStrategy dossiers it's under Text & Media) and make sure it is set to run HTML/JavaScript rather than as an iframe.
  4. Paste the chart snippet. Copy the snippet from the chart's page. If your column headers differ from the defaults, add data-columns to map them, e.g. {"month":"Order Month","dimA":"Region","v1":"Orders"}.
  5. Set the date format if needed. Dates like 'November, 2025', '2026 W44' or 20261023 are detected automatically. If yours are unusual, set data-date-format, e.g. "MMMM, YYYY".
  6. View the dashboard. The chart finds the grid by its headers, reads every row and draws itself. It re-reads when filters or selectors change the grid.

Troubleshooting

  • “Couldn't find the grid” / “No metrics found” A header in data-columns doesn't match the grid exactly. Matching ignores spaces and capitals, but not other characters – copy the header text from the grid.
  • Only part of the data shows Incremental fetch is on, or the grid is in a panel that hasn't drawn yet. Turn off incremental fetch and make the grid tall.
  • Labels merge, e.g. “North North South” Frozen panes can draw row headers out of step with values. Use the latest chart version, which lines cells up by their position on screen.
  • Blank chart after updating the snippet The new script may not be live yet, or a cached 404 is being served. Wait a minute and reload; check the browser console for an integrity error.
  • The chart re-reads when the window is resized MicroStrategy can rebuild the container on resize. Set data-refresh="manual" to only re-read when you press Refresh data.

Common questions

Can you add custom charts to MicroStrategy without a plugin?

Yes. Add an HTML container to a dossier or dashboard, paste a script that reads a grid on the same page, and the script draws the chart. No visualization plugin, admin install or server is needed.

Why does my custom chart only show some of the rows?

MicroStrategy grids load rows in blocks (incremental fetch). Turn off incremental fetch on the grid, or make the grid tall, so every row is available to read.

Is it safe to load an external script in MicroStrategy?

Pin it with a Subresource Integrity (SRI) hash: the browser refuses to run the script if a single byte changes. The script only reads what the viewer can already see and sends nothing anywhere.
