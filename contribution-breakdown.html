What is a Contribution Breakdown Chart?

A contribution breakdown shows how much each segment contributes to a total, split by further dimensions, for value, volume or value per unit. This Contribution Breakdown is free to copy and paste: it reads a grid on the same page – in a MicroStrategy (Strategy One) dashboard's HTML container, or any web page – and draws itself in the browser, with no plugin, server or data upload.

When to use it

Use it when you would normally chart cohorts by month, but the thing to compare is a group instead – a licence, a region, a brand – and you want to see where its value comes from.

Questions it answers

  • Which group brings in the most total value, and from which segments?
  • Is a group big because of volume, or because each unit is worth more?
  • How does the mix of segments differ from one group to the next?

How to use it

  1. On your dashboard page, add a grid with the columns below (or map your own header names – see below). Keep it on the same page – tuck it behind the chart rather than hiding it, and make it tall.
  2. Add an HTML container (one that runs JavaScript) and paste the snippet.
  3. View the page. The chart finds the grid, reads every row and draws itself; it updates when filters change the grid.

Your own column names

The chart looks for the default headers above. If your grid's headers are different, map them by key with data-columns on the placeholder – the chart then shows your names too. data-labels (same keys) changes just the on-screen names, and data-title changes the heading. For grids that draw rows in batches, data-grid-class and data-scroll-class name the grid's container and its scroll box so every row is read.

What it does

  • One bar per item of Dimension A, sorted by the value shown
  • Show: total value (units × value per unit), units, or value per unit (weighted), with a dot per segment
  • Split by Dimension B or C, or none; the biggest 6 segments get their own colour and the rest are grouped as Other
  • Mix % shows each bar as 100% to compare make-up
  • Cards for total value, the biggest item, the highest value per unit and the top segment, plus a ranked list
  • Hover any segment for its value, share and value per unit
  • No Chart.js needed – drawn as SVG

Data & security

  • Reads only what is drawn on the page for the viewer, so the viewer's normal permissions still apply
  • Calculations happen in the viewer's browser; nothing is uploaded or sent anywhere
  • The only download is this script, integrity-checked
  • No logins, API keys, cookies or browser storage
