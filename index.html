Free Chart.js charts for dashboard HTML containers

Custom charts that sit inside an HTML container

Each chart reads a normal grid on the same dashboard page and redraws it as a richer visual – cards, toggles, segments, heatmaps, filters. Pick a chart to see it running on random data and copy its snippet.

1

Add a grid

Put a grid with the chart's columns on the page. It's the data source – tuck it behind the chart.

2

Paste the snippet

Add an HTML container and paste the chart's snippet. It loads the pinned chart script from here.

3

View

The chart reads every row of the grid and follows filters automatically.

Safe by design

No data leaves the page

Charts read what the page shows the viewer and calculate in their browser. Nothing is uploaded.

Pinned & integrity-checked

Every script is versioned and loaded with an SRI hash, so altered code is refused before it runs.

Permissions still apply

Charts only see rows the viewer is allowed to see. No logins, keys or API calls.

Questions

How do I put a custom chart in a dashboard HTML container?

Add a grid with the chart's columns to the same dashboard page, add an HTML container that runs JavaScript, and paste the chart's snippet. The chart finds the grid, reads every row and draws itself.

Does any data leave the page?

No. The chart reads the grid that is already drawn in the viewer's browser and does every calculation there. The only network requests load the chart script and Chart.js, both checked with an SRI hash.

My grid's column names are different – can I still use a chart?

Yes. Map your headers to the chart's keys with a data-columns attribute on the placeholder, e.g. data-columns='{"v1":"Revenue"}'. The chart then shows your names.

Does it work with large grids?

Yes. If the grid only draws the rows on screen, the chart scrolls through it, waits for each batch and only draws once every row has been read.

Is it free to use?

The charts are published openly on GitHub Pages with copy-paste snippets. Chart.js is MIT-licensed.
