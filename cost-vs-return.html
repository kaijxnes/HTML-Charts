How to use it

  1. On your dashboard page, add a grid with the columns below (or map your own header names – see below). Keep it on the same page – tuck it behind the chart rather than hiding it, and make it tall.
  2. Add an HTML container (HTML Text mode) and paste the snippet.
  3. View the page. The chart finds the grid, reads every row and draws itself; it updates when filters change the grid.

Your own column names

The chart looks for the default headers above. If your grid's headers are different, map them by key with data-columns on the placeholder – the chart then shows your names too. data-labels (same keys) changes just the on-screen names, and data-title changes the heading. For grids that draw rows in batches, data-grid-class and data-scroll-class name the grid's container and scroll box.

Example
<div data-chart-embed="cost-vs-return" data-columns='{"month":"Your Month Header","cost":"Your Metric Header"}' data-title="Your title" style="height:100%"></div>

What it does

  • Net return, ROI and ROAS, cost, return, cost per unit and count cards
  • Cost vs return bars with an ROI line and break-even marker
  • Cost per unit vs value per unit, shaded green where value is higher
  • Monthly table with totals
  • Rows with no month key are left out and counted in the subtitle

Data & security

  • Reads only what is drawn on the page for the viewer, so the viewer's normal permissions still apply
  • Calculations happen in the viewer's browser; nothing is uploaded or sent anywhere
  • The only downloads are this script and Chart.js, both integrity-checked
  • No logins, API keys, cookies or browser storage
