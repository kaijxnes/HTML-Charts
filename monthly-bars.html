Monthly Bars

A $ metric by month as bars, with a toggle between three metrics, 6-month average cards and a second metric as a line.

How to use it

  1. On your dashboard page, add a grid with the columns below (or map your own header names – see below). Keep it on the same page – tuck it behind the chart rather than hiding it, and make it tall.
  2. Add an HTML container (one that runs JavaScript) and paste the snippet.
  3. View the page. The chart finds the grid, reads every row and draws itself; it updates when filters change the grid.

Your own column names

The chart looks for the default headers above. If your grid's headers are different, map them by key with data-columns on the placeholder – the chart then shows your names too. data-labels (same keys) changes just the on-screen names, and data-title changes the heading.

Example
<div data-chart-embed="monthly-bars" data-columns='{"month":"Your Month Header","v12":"Your Metric Header"}' data-title="Your title" style="height:100%"></div>

What it does

  • Bars for the chosen metric by month; click a card or button to switch
  • Cards with the 6-month average of each metric
  • Dashed average line; months outside the window are faded
  • Metric 4 as a line on its own axis
  • Optional low-volume flag: add data-min-volume="600" to stripe and badge months where Metric 4 is below that (on in this demo)

Data & security

  • Reads only what is drawn on the page for the viewer, so the viewer's normal permissions still apply
  • Calculations happen in the viewer's browser; nothing is uploaded or sent anywhere
  • The only downloads are this script and Chart.js, both integrity-checked
  • No logins, API keys, cookies or browser storage
