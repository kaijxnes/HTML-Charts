What is a Ribbon Chart?

A ribbon chart is a stacked column chart where segments are re-ranked in every period and joined by ribbons, showing changes in rank and size. This Ribbon Chart is free to copy and paste: it reads a grid on the same page – in a MicroStrategy (Strategy One) dashboard's HTML container, or any web page – and draws itself in the browser, with no plugin, server or data upload.

When to use it

Use it when you want month-by-month totals for a few segments and care about which one leads – the ribbons make every change in rank easy to spot.

Questions it answers

  • Which segment was biggest each month, and when did that change?
  • Is a segment growing in its own right, or just overtaking a shrinking one?
  • How big is each segment over the last 12 months?

How to use it

  1. On your dashboard page, add a grid with the columns below (or map your own header names – see below). Keep it on the same page – tuck it behind the chart rather than hiding it, and make it tall.
  2. Add an HTML container (one that runs JavaScript) and paste the snippet.
  3. View the page. The chart finds the grid, reads every row and draws itself; it updates when filters change the grid.

Your own column names

The chart looks for the default headers above. If your grid's headers are different, map them by key with data-columns on the placeholder – the chart then shows your names too. data-labels (same keys) changes just the on-screen names, and data-title changes the heading. For grids that draw rows in batches, data-grid-class and data-scroll-class name the grid's container and its scroll box so every row is read.

Example
<div data-chart-embed="ribbon-chart" data-columns='{"month":"Your Month Header","v1":"Your Metric Header"}' data-title="Your title" style="height:100%"></div>

What it does

  • One column per month, split by segment with the biggest on top
  • Ribbons join each segment from month to month – where ribbons cross, the ranking changed
  • Show values or share %; Range 12 or 24 months, or 13, 26 or 52 weeks for weekly grids (e.g. 2026 W45), or all
  • Cards for the latest total, the top segment, the fastest grower and the biggest climb in rank
  • Side list of each segment's total over the range and its rank first → latest month
  • Hover a column or ribbon to highlight that segment and see its values, change and rank
  • Starting choices: data-show="share", data-range="24" or "all"
  • No Chart.js needed – drawn as SVG

Data & security

  • Reads only what is drawn on the page for the viewer, so the viewer's normal permissions still apply
  • Calculations happen in the viewer's browser; nothing is uploaded or sent anywhere
  • The only download is this script, integrity-checked
  • No logins, API keys, cookies or browser storage
