What is a Target Pacing Chart?

A target pacing chart tracks progress through a period against where you should be by now to hit target. This Target Pacing is free to copy and paste: it reads a grid on the same page – in a MicroStrategy (Strategy One) dashboard's HTML container, or any web page – and draws itself in the browser, with no plugin, server or data upload.

When to use it

Use it during a month to see whether you're on track to hit target, and what each remaining day needs to deliver.

Questions it answers

  • Are we ahead or behind target so far this month?
  • Where will we land at month end?
  • How much do we need per day to hit target?

How to use it

  1. On your dashboard page, add a grid with the columns below (or map your own header names – see below). Keep it on the same page – tuck it behind the chart rather than hiding it, and make it tall.
  2. Add an HTML container (one that runs JavaScript) and paste the snippet.
  3. View the page. The chart finds the grid, reads every row and draws itself; it updates when filters change the grid.
Default headerKeyWhat it's for
DatedateRequiredA daily date. Future days can have a target and no actual.
Metric 1v1RequiredThe actual for the day.
Metric 2v2OptionalThe target for the day – without it you get a run-rate projection.

Auto-detect reads all of these. Pick one to pin it – the snippet below updates. Tokens: YYYY MM MMM MMMM DD ww (week); anything else is matched as written.

Your own column names

The chart looks for the default headers above. If your grid's headers are different, map them by key with data-columns on the placeholder – the chart then shows your names too. data-labels (same keys) changes just the on-screen names, and data-title changes the heading. For grids that draw rows in batches, data-grid-class and data-scroll-class name the grid's container and its scroll box so every row is read.

<div data-chart-embed="target-pacing" data-columns='{"date": "Your Date Header", "v1": "Your Metric Header"}' data-title="Your title" style="height:100%"></div>

What it does

  • Daily bars with cumulative actual and cumulative target lines
  • Month-end projection on the target's daily shape (or the run rate if there's no target)
  • Cards for actual and target to date, projected month end and the daily rate needed
  • Pick any month in the grid

Data & security

  • Reads only what is drawn on the page for the viewer, so the viewer's normal permissions still apply
  • Calculations happen in the viewer's browser; nothing is uploaded or sent anywhere
  • The only downloads are this script and Chart.js, both integrity-checked
  • No logins, API keys, cookies or browser storage
