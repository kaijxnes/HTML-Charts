Venn diagram vs UpSet plot

A Venn diagram is clearest for two or three groups – everyone understands overlapping circles. From four groups up, a Venn gets unreadable, and an UpSet plot – one bar per combination with a dot matrix showing which groups it contains – shows the same information far more clearly.

Common questions

When should I use an UpSet plot instead of a Venn diagram?

When there are four or more groups, or when you need to rank combinations by size. Venn diagrams with four or more sets have too many small regions to read.

What data do both charts need?

One row per combination (e.g. 'A & B') with a count of how many are in exactly that combination.
